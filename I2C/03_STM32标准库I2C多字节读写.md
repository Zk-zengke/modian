# 03 STM32 标准库 I2C 多字节读写

本文使用 STM32 标准库 SPL 讲解 I2C 多字节写和多字节读。

示例环境：

```text
芯片：STM32F10x，例如 STM32F103
库：Standard Peripheral Library
I2C：I2C1
SCL：PB6
SDA：PB7
设备示例：MPU6050
设备 7 位地址：0x68
标准库传入地址：0x68 << 1 = 0xD0
```

## 1. 多字节写是什么

多字节写就是一次 I2C 通信中，向从机连续写入多个数据字节。

常见用途：

```text
连续配置多个寄存器
向 EEPROM 连续写入多个字节
向 OLED 连续发送显示数据
向传感器写入一组初始化参数
```

常见格式：

```text
START
Addr + W
ACK
RegAddr
ACK
Data0
ACK
Data1
ACK
Data2
ACK
...
STOP
```

简写：

```text
S -> Addr+W -> ACK -> RegAddr -> ACK -> Data0 -> ACK -> Data1 -> ACK -> ... -> P
```

其中：

```text
Addr：从机地址
W：写方向，R/W 位为 0
RegAddr：起始寄存器地址
Data0、Data1：要连续写入的数据
```

很多芯片支持寄存器地址自动递增。

例如从 `0x10` 寄存器开始写 3 个字节：

```text
0x10 <- Data0
0x11 <- Data1
0x12 <- Data2
```

是否支持自动递增，要看芯片数据手册。

## 2. 多字节读是什么

多字节读就是一次 I2C 通信中，从从机连续读取多个数据字节。

常见用途：

```text
一次读取温度高低字节
一次读取加速度 X/Y/Z 的 6 个字节
一次读取陀螺仪 X/Y/Z 的 6 个字节
一次读取传感器的一组状态数据
```

典型寄存器读流程：

```text
START
Addr + W
ACK
RegAddr
ACK
RESTART
Addr + R
ACK
Data0
ACK
Data1
ACK
Data2
ACK
...
LastData
NACK
STOP
```

简写：

```text
S -> Addr+W -> ACK -> RegAddr -> ACK
Sr -> Addr+R -> ACK
Data0 -> ACK -> Data1 -> ACK -> LastData -> NACK -> P
```

注意：

```text
前面的字节后面，主机给 ACK，表示还要继续读。
最后一个字节后面，主机给 NACK，表示读完了。
```

## 3. 初始化 I2C1

PB6 是 SCL，PB7 是 SDA。

I2C 引脚要配置为复用开漏输出：

```c
#include "stm32f10x.h"

void I2C1_Init_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    I2C_InitTypeDef I2C_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_I2C1, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_6 | GPIO_Pin_7;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_OD;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_InitStructure);

    I2C_InitStructure.I2C_Mode = I2C_Mode_I2C;
    I2C_InitStructure.I2C_DutyCycle = I2C_DutyCycle_2;
    I2C_InitStructure.I2C_OwnAddress1 = 0x00;
    I2C_InitStructure.I2C_Ack = I2C_Ack_Enable;
    I2C_InitStructure.I2C_AcknowledgedAddress = I2C_AcknowledgedAddress_7bit;
    I2C_InitStructure.I2C_ClockSpeed = 100000;

    I2C_Init(I2C1, &I2C_InitStructure);
    I2C_Cmd(I2C1, ENABLE);
}
```

注意：

```text
SCL 和 SDA 需要上拉电阻。
常见上拉电阻是 4.7k。
如果模块板已经带上拉电阻，可以不用重复外接。
```

## 4. 等待事件函数

标准库 I2C 通信经常要等待事件。

为了避免死等，先写一个带超时的等待函数：

```c
#define I2C_TIMEOUT  10000

static uint8_t I2C_WaitEvent(I2C_TypeDef *I2Cx, uint32_t event)
{
    uint32_t timeout = I2C_TIMEOUT;

    while (I2C_CheckEvent(I2Cx, event) != SUCCESS)
    {
        if (timeout-- == 0)
        {
            return 1;
        }
    }

    return 0;
}
```

返回值：

```text
0：等待成功
1：等待超时
```

## 5. 等待总线空闲

开始通信前，最好确认 I2C 总线空闲。

```c
static uint8_t I2C_WaitBusy(void)
{
    uint32_t timeout = I2C_TIMEOUT;

    while (I2C_GetFlagStatus(I2C1, I2C_FLAG_BUSY))
    {
        if (timeout-- == 0)
        {
            return 1;
        }
    }

    return 0;
}
```

总线空闲时：

```text
SCL = 高电平
SDA = 高电平
```

如果一直 BUSY，可能是：

```text
SDA 被从机拉低
SCL 被拉低
通信中途异常停止
上拉电阻或接线有问题
```

## 6. 多字节写函数
函数功能：

```text
从指定寄存器开始，连续写入 len 个字节。
```

代码：

```c
uint8_t I2C_WriteRegisters(uint8_t dev_addr, uint8_t reg_addr, uint8_t *buf, uint8_t len)
{
    uint8_t i;

    if (len == 0)
    {
        return 1;
    }

    if (I2C_WaitBusy())
    {
        return 2;
    }

    I2C_GenerateSTART(I2C1, ENABLE);
    if (I2C_WaitEvent(I2C1, I2C_EVENT_MASTER_MODE_SELECT))
    {
        I2C_GenerateSTOP(I2C1, ENABLE);
        return 3;
    }

    I2C_Send7bitAddress(I2C1, dev_addr, I2C_Direction_Transmitter);
    if (I2C_WaitEvent(I2C1, I2C_EVENT_MASTER_TRANSMITTER_MODE_SELECTED))
    {
        I2C_GenerateSTOP(I2C1, ENABLE);
        return 4;
    }

    I2C_SendData(I2C1, reg_addr);
    if (I2C_WaitEvent(I2C1, I2C_EVENT_MASTER_BYTE_TRANSMITTED))
    {
        I2C_GenerateSTOP(I2C1, ENABLE);
        return 5;
    }

    for (i = 0; i < len; i++)
    {
        I2C_SendData(I2C1, buf[i]);

        if (I2C_WaitEvent(I2C1, I2C_EVENT_MASTER_BYTE_TRANSMITTED))
        {
            I2C_GenerateSTOP(I2C1, ENABLE);
            return 6;
        }
    }

    I2C_GenerateSTOP(I2C1, ENABLE);

    return 0;
}
```

参数：

```text
dev_addr：从机地址，标准库里通常传 7 位地址左移后的值，例如 0xD0
reg_addr：起始寄存器地址
buf：要写入的数据数组
len：写入字节数
```

返回值：

```text
0：成功
非 0：失败，数字表示失败步骤
```

使用示例：

```c
#define MPU6050_ADDR  0xD0

uint8_t config[2];

config[0] = 0x00;
config[1] = 0x18;

I2C_WriteRegisters(MPU6050_ADDR, 0x1B, config, 2);
```

这表示：

```text
从 0x1B 寄存器开始连续写 2 个字节。
0x1B <- 0x00
0x1C <- 0x18
```

前提是这个芯片支持寄存器地址自动递增。

## 7. 多字节读函数

函数功能：

```text
从指定寄存器开始，连续读取 len 个字节。
```

代码：

```c
uint8_t I2C_ReadRegisters(uint8_t dev_addr, uint8_t reg_addr, uint8_t *buf, uint8_t len)
{
    uint8_t i;

    if (len == 0)
    {
        return 1;
    }

    if (I2C_WaitBusy())
    {
        return 2;
    }

    I2C_GenerateSTART(I2C1, ENABLE);
    if (I2C_WaitEvent(I2C1, I2C_EVENT_MASTER_MODE_SELECT))
    {
        I2C_GenerateSTOP(I2C1, ENABLE);
        return 3;
    }

    I2C_Send7bitAddress(I2C1, dev_addr, I2C_Direction_Transmitter);
    if (I2C_WaitEvent(I2C1, I2C_EVENT_MASTER_TRANSMITTER_MODE_SELECTED))
    {
        I2C_GenerateSTOP(I2C1, ENABLE);
        return 4;
    }

    I2C_SendData(I2C1, reg_addr);
    if (I2C_WaitEvent(I2C1, I2C_EVENT_MASTER_BYTE_TRANSMITTED))
    {
        I2C_GenerateSTOP(I2C1, ENABLE);
        return 5;
    }

    I2C_GenerateSTART(I2C1, ENABLE);
    if (I2C_WaitEvent(I2C1, I2C_EVENT_MASTER_MODE_SELECT))
    {
        I2C_GenerateSTOP(I2C1, ENABLE);
        return 6;
    }

    I2C_Send7bitAddress(I2C1, dev_addr, I2C_Direction_Receiver);
    if (I2C_WaitEvent(I2C1, I2C_EVENT_MASTER_RECEIVER_MODE_SELECTED))
    {
        I2C_GenerateSTOP(I2C1, ENABLE);
        return 7;
    }

    for (i = 0; i < len; i++)
    {
        if (i == len - 1)
        {
            I2C_AcknowledgeConfig(I2C1, DISABLE);
            I2C_GenerateSTOP(I2C1, ENABLE);
        }
        else
        {
            I2C_AcknowledgeConfig(I2C1, ENABLE);
        }

        if (I2C_WaitEvent(I2C1, I2C_EVENT_MASTER_BYTE_RECEIVED))
        {
            I2C_GenerateSTOP(I2C1, ENABLE);
            I2C_AcknowledgeConfig(I2C1, ENABLE);
            return 8;
        }

        buf[i] = I2C_ReceiveData(I2C1);
    }

    I2C_AcknowledgeConfig(I2C1, ENABLE);

    return 0;
}
```

参数：

```text
dev_addr：从机地址，标准库里通常传 7 位地址左移后的值，例如 0xD0
reg_addr：起始寄存器地址
buf：接收数据的数组
len：读取字节数
```

使用示例：

```c
uint8_t buf[6];

I2C_ReadRegisters(MPU6050_ADDR, 0x3B, buf, 6);
```

这表示：

```text
从 0x3B 寄存器开始连续读 6 个字节。
```

例如 MPU6050：

```text
0x3B：ACCEL_XOUT_H
0x3C：ACCEL_XOUT_L
0x3D：ACCEL_YOUT_H
0x3E：ACCEL_YOUT_L
0x3F：ACCEL_ZOUT_H
0x40：ACCEL_ZOUT_L
```

## 8. 单字节写和单字节读也可以复用

写 1 个字节：

```c
uint8_t I2C_WriteRegister(uint8_t dev_addr, uint8_t reg_addr, uint8_t data)
{
    return I2C_WriteRegisters(dev_addr, reg_addr, &data, 1);
}
```

读 1 个字节：

```c
uint8_t I2C_ReadRegister(uint8_t dev_addr, uint8_t reg_addr, uint8_t *data)
{
    return I2C_ReadRegisters(dev_addr, reg_addr, data, 1);
}
```

这样可以减少重复代码。

## 9. 多字节数据组合

I2C 一次传 1 个字节。

如果传感器数据是 16 位，就要用两个字节组合。

例如读取到：

```text
buf[0] = 高字节
buf[1] = 低字节
```

组合方式：

```c
uint16_t value = ((uint16_t)buf[0] << 8) | buf[1];
```

如果是有符号 16 位数据：

```c
int16_t value = ((int16_t)buf[0] << 8) | buf[1];
```

例如 MPU6050 加速度：

```c
int16_t ax;
int16_t ay;
int16_t az;
uint8_t buf[6];

I2C_ReadRegisters(MPU6050_ADDR, 0x3B, buf, 6);

ax = ((int16_t)buf[0] << 8) | buf[1];
ay = ((int16_t)buf[2] << 8) | buf[3];
az = ((int16_t)buf[4] << 8) | buf[5];
```

含义：

```text
X 轴：buf[0] 高字节，buf[1] 低字节
Y 轴：buf[2] 高字节，buf[3] 低字节
Z 轴：buf[4] 高字节，buf[5] 低字节
```

## 10. MPU6050 示例

宏定义：

```c
#define MPU6050_ADDR          0xD0
#define MPU6050_WHO_AM_I      0x75
#define MPU6050_PWR_MGMT_1    0x6B
#define MPU6050_ACCEL_XOUT_H  0x3B
```

初始化：

```c
uint8_t MPU6050_Init(void)
{
    uint8_t id;

    if (I2C_ReadRegister(MPU6050_ADDR, MPU6050_WHO_AM_I, &id))
    {
        return 1;
    }

    if (id != 0x68)
    {
        return 2;
    }

    if (I2C_WriteRegister(MPU6050_ADDR, MPU6050_PWR_MGMT_1, 0x00))
    {
        return 3;
    }

    return 0;
}
```

读取加速度：

```c
uint8_t MPU6050_ReadAccel(int16_t *ax, int16_t *ay, int16_t *az)
{
    uint8_t buf[6];

    if (I2C_ReadRegisters(MPU6050_ADDR, MPU6050_ACCEL_XOUT_H, buf, 6))
    {
        return 1;
    }

    *ax = ((int16_t)buf[0] << 8) | buf[1];
    *ay = ((int16_t)buf[2] << 8) | buf[3];
    *az = ((int16_t)buf[4] << 8) | buf[5];

    return 0;
}
```

main 中调用：

```c
int main(void)
{
    int16_t ax;
    int16_t ay;
    int16_t az;

    SystemInit();
    I2C1_Init_Config();

    if (MPU6050_Init() != 0)
    {
        while (1)
        {
            /* 初始化失败 */
        }
    }

    while (1)
    {
        if (MPU6050_ReadAccel(&ax, &ay, &az) == 0)
        {
            /* ax、ay、az 是原始加速度数据 */
        }
    }
}
```

## 11. 地址一定不要弄混

MPU6050 的 7 位地址是：

```text
0x68
```

标准库代码里常写：

```c
#define MPU6050_ADDR  0xD0
```

因为：

```text
0x68 << 1 = 0xD0
```

发送方向由函数决定：

```c
I2C_Send7bitAddress(I2C1, dev_addr, I2C_Direction_Transmitter);
I2C_Send7bitAddress(I2C1, dev_addr, I2C_Direction_Receiver);
```

不要这样写：

```c
I2C_Send7bitAddress(I2C1, 0xD1, I2C_Direction_Receiver);
```

更稳妥的写法是：

```c
#define MPU6050_ADDR_7BIT  0x68
#define MPU6050_ADDR       (MPU6050_ADDR_7BIT << 1)
```

这样可以看出 `0xD0` 是由 `0x68` 左移得到的。

## 12. 常见问题

### 1. 卡在 BUSY

可能原因：

```text
SDA 被拉低
SCL 被拉低
没有上拉电阻
通信中途异常
从机死锁
```

可以用示波器或逻辑分析仪看空闲时：

```text
SCL 是否为高
SDA 是否为高
```

### 2. 地址阶段失败

如果卡在：

```c
I2C_EVENT_MASTER_TRANSMITTER_MODE_SELECTED
```

常见原因：

```text
地址错了
设备没供电
SCL/SDA 接反
没有共地
没有上拉电阻
设备不是 0x68
```

### 3. 读多字节最后一个字节要 NACK

多字节读时：

```text
前面字节 ACK
最后字节 NACK
```

代码中最后一个字节前关闭 ACK：

```c
I2C_AcknowledgeConfig(I2C1, DISABLE);
I2C_GenerateSTOP(I2C1, ENABLE);
```

读完后再恢复 ACK：

```c
I2C_AcknowledgeConfig(I2C1, ENABLE);
```

### 4. 寄存器是否自动递增

连续读写依赖从机内部寄存器地址自动递增。

有些芯片默认支持，有些芯片需要设置自动递增位，有些芯片不支持。

所以连续读写前要看数据手册。

## 13. 总结

多字节写：

```text
S -> Addr+W -> ACK -> RegAddr -> ACK -> Data0 -> ACK -> Data1 -> ACK -> ... -> P
```

多字节读：

```text
S -> Addr+W -> ACK -> RegAddr -> ACK
Sr -> Addr+R -> ACK
Data0 -> ACK -> Data1 -> ACK -> LastData -> NACK -> P
```

标准库关键函数：

```c
I2C_GenerateSTART()
I2C_Send7bitAddress()
I2C_SendData()
I2C_ReceiveData()
I2C_AcknowledgeConfig()
I2C_GenerateSTOP()
```

最重要的点：

```text
写：主机连续发送数据，从机每字节 ACK。
读：从机连续发送数据，主机前面 ACK，最后 NACK。
地址：标准库里通常传 7 位地址左移后的值。
```
