# modian

模电学习（有利于学习记忆的内容格式）

## 推荐学习记录格式

### 1) 知识卡片（每个知识点一张）
- **主题**：
- **核心结论（一句话）**：
- **关键公式/规律**：
- **适用条件**：
- **典型例题思路（3~5步）**：
- **易错点**：
- **记忆钩子（类比/口诀）**：

### 2) 复习节奏
- **当天**：完成知识卡片 + 1次口头复述
- **第2天**：只看“核心结论 + 易错点”快速回忆
- **第7天**：做1道综合题并复盘

### 3) 输出要求
- 每条尽量短句，先结论后解释
- 公式配一句“什么时候用”
- 每页只保留一个重点，避免信息过载
